How It Works
A plain-language guide to understanding and managing the VotePH system.
✅
No internet or server required. Everything runs locally inside your browser. Votes are stored on this computer and are instantly visible in this admin panel.
How voting works, step by step
🗂️
Step 1 — Voter opens the voting page
A voter goes to ph_voting_platform.html on the same computer or in another browser tab. This is the page they use to cast their vote.
🔐
Step 2 — Voter logs in with their Voter ID
The system checks if that Voter ID has already voted. If it has, the voter is blocked and shown a message with the date and receipt of their earlier vote. Each Voter ID can only vote once.
Duplicate protection is automatic
🗳️
Step 3 — Voter selects candidates and submits
The voter picks up to 12 senators and up to 3 party-list groups, reviews their ballot, then clicks Submit. A unique receipt ID is generated for their records.
💾
Step 4 — Vote is saved to the browser
As soon as a vote is submitted, all vote tallies are saved to this browser's local storage — think of it like a small built-in database on your computer. No data is sent over the internet.
📊
Step 5 — Admin panel updates automatically
This admin page reads from that same local storage. If a vote is submitted in another tab, this page detects it instantly and updates the tallies. It also re-checks every 5 seconds as a backup.
Auto-refresh every 5 seconds
Things you can do as admin
⬇️
Export results to a spreadsheet
Click Export votes.csv on the Live Votes tab to download all vote counts for senators, party-list groups, and cities into a file you can open in Excel or Google Sheets.
🖥️
Watch voting happen in real time (Bridge tab)
The Bridge tab embeds the voting page directly inside this admin panel. You can watch or assist a voter while seeing tallies update live without switching tabs.
🗑️
Reset all votes
The Reset all votes button permanently wipes all vote data. Use this only before starting a fresh election session — it cannot be undone.
Permanent — cannot be undone
Important things to know
⚠️
Same browser, same computer only. Votes cast on a different computer or a different browser (e.g. Chrome vs Firefox) will not appear here. All devices must use the same browser on the same machine.
⚠️
Clearing browser data will delete all votes. If anyone clears their browser history or site data, all vote records will be permanently lost. Avoid doing this during or after an election.
🚫
Do not use private/incognito mode for voting. Incognito windows have separate storage and votes cast there will not be saved to the main admin tally.
